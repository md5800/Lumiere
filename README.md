# LUMIÈRE BOTANICALS – Luxury Beauty & Skincare E-Commerce Website

A modern, high-performance, responsive luxury beauty and skincare e-commerce website built with **React**, **Vite**, **Bootstrap 5 Grid**, and **Tailwind CSS**.

---

## 🌿 Overview & Architecture

Inspired by the provided reference video and screenshot, the project meticulously implements every visible section with organic styling, dark forest-green accents (`#163323`), warm gold highlights (`#C59A58`), and clean typography.

### Exact Section Sequence:
1. **Header & Navigation Bar**:
   - Top announcement strip with live promo ticker, currency selector, and track order link.
   - Luxury branding with leaf emblem (`LUMIÈRE Botanicals`).
   - Sticky navigation menu with category dropdowns.
   - Instant search trigger, wishlist counter badge, interactive cart counter & subtotal pill.
   - Mobile responsive slide-out drawer menu.

2. **Hero / Promotional Banner Section**:
   - Dual luxury promotional banner grid with rich model photography and cold-pressed botanical highlights.
   - Core value guarantees strip: 100% Organic & Vegan, Free Worldwide Express Shipping, Dermatologist Backed, 30-Day Glow Promise.

3. **About Us Section** *(Exact match to reference image)*:
   - 4-photo organic rounded collage with central circular botanical emblem badge (`100% ORGANIC NATURAL PURE FORMULA`).
   - Headline: *"Your Journey to Effortless Elegance"* with warm gold serif highlight.
   - Dark Forest Green metrics card (`24+ Categories`, `2500+ Products`, `99% Satisfied Customer`).
   - Handwritten cursive signature by founder *Jenny Alexander*.

4. **Our Best Sellers / Products Section** *(Exact match to reference image)*:
   - Subtitle: *"Our Products"* | Headline: *"Our Best Sellers Products"*.
   - Filterable category pills: `All`, `Skin Care`, `Make Up`, `Hair Care`, `Fragrances`, `Nail Care`, `Body Care`, `Accessories & Tools`.
   - Reusable product cards with discount pills (`50% off`, `20% off`, etc.), star ratings, price comparisons, and action icons (Wishlist, Quick View, Add to Cart).
   - Live real-time countdown bar on the featured card (`SilkSculpt Serum`).

5. **Special Savings / Summer Glow Deals** *(Exact match to reference image)*:
   - Three-panel layout with dual framed model portraits flanking the center card.
   - Cream card framed with custom tropical palm fronds.
   - Live real-time countdown timer (`Days : Hours : Minutes : Seconds`).
   - Call to action: *"Shop Now →"*.

6. **Scrolling Product Category Ticker** *(Exact match to reference image)*:
   - Full-width dark forest green bar with infinite smooth marquee loop and golden botanical leaf separators.

7. **Deals of the Day Section**:
   - Limited-time flash deals with live expiration countdown and stock progress bars (`Sold: X / Y`).

8. **Why Choose Us / Botanical Standards**:
   - 4 feature cards: Cold-Pressed Actives, Dermatologist Backed, Cruelty-Free & Vegan, Biophotonic Glass Packaging.

9. **Customer Reviews / Testimonials Slider**:
   - Swiper.js carousel with 5-star verified buyer reviews and reviewer portraits.

10. **Instagram Feed / Community Showcase**:
    - `@LumiereBotanicals` 6-item photo grid with hover engagement overlays.

11. **VIP Newsletter Subscription Banner**:
    - *"Unlock 15% Off Your First Ritual"* luxury form with instant feedback.

12. **Comprehensive Footer**:
    - Brand story, ritual categories, customer care links, contact information, secure payment badges, and back-to-top button.

13. **Interactive E-Commerce Modals & Drawers**:
    - **Slide-out Cart Drawer**: Items list, quantity controls, delete item, free shipping progress bar ($75 threshold), coupon code system (`GLOW20` for 20% off, `SUMMER50` for 50% off), total breakdown.
    - **Wishlist Drawer**: Saved items with one-click "Move to Cart".
    - **Quick View Modal**: Deep product inspection, image switcher, active ingredients, volume selector, quantity selector, add to cart.
    - **Live Search Modal**: Real-time product search with keyword matching and popular tags.
    - **Toast Notifications**: Animated bottom-right feedback on shopping actions.

## 🛠️ Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS 3.4**
- **Bootstrap 5 (Grid Utilities)**
- **Lucide React**
- **Swiper 12**
- **Google Fonts** (`Playfair Display`, `Plus Jakarta Sans`, `Alex Brush`)

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
